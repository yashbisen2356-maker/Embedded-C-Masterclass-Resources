=> What is Mc - It is a small computer system on a single chip but its resources and capabilities, such as memory and speed and internal interfaces are very limited than desktop 
                because MC is targeted embedded application based device.

=>typicla MC has volatile and non volatile memories ,input/output pins , clock , bus interface on a single chip.
